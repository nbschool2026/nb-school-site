# Структура проєкту

## Папки

```text
nb-school-site/
├─ cms/                 Strapi 5: API, адмінка, схеми контенту
│  ├─ config/            сервер, SQLite, CORS, плагіни
│  ├─ src/api/           моделі, маршрути, контролери, сервіси
│  └─ src/index.ts       стартові записи та публічні права читання
├─ frontend/            React 18, Vite 5, React Router 6
│  ├─ seed-media/        оптимізовані стартові WebP для CMS
│  └─ src/
│     ├─ pages/          сторінки
│     ├─ components/     спільні елементи
│     └─ lib/            API-клієнт і демонстраційні дані
├─ docs/                документація та плани
├─ backups/             очищений знімок демонстраційної бази CMS
├─ index.html           попередня статична версія
├─ about.html
├─ events.html
├─ public-info.html
└─ js/                  підключення попередньої версії до CMS
```

## Потік даних

```text
Адміністратор → Strapi Admin → SQLite (.tmp/data.db)
                                ↓ опубліковані записи
Відвідувач → React/Vite → Strapi REST API
                    ↘ локальні fallbackData.js лише для розкладу й документів
```

`frontend/src/lib/api.js` формує запити до `/api` через Vite-проксі, нормалізує відповіді Strapi та адреси медіа. Сторінки завантажують дані після відкриття через `useEffect`. Автоматичного оновлення відкритої сторінки після змін у CMS немає: її потрібно перезавантажити.

## Сторінки React

| Маршрут | Файл | Дані CMS |
| --- | --- | --- |
| `/` | `frontend/src/pages/HomePage.jsx` | Профіль школи, чотири найновіші події, розклад, перший працівник |
| `/about` | `frontend/src/pages/AboutPage.jsx` | Історія, цінності, працівники |
| `/events` | `frontend/src/pages/EventsPage.jsx` | Події |
| `/public-info` | `frontend/src/pages/PublicInfoPage.jsx` | Публічні документи |

Навігація, частина пояснювальних текстів і параметри розкладу зараз записані безпосередньо у компонентах React. Календар подій створюється динамічно. Головне фото, фото сторінки «Про нас», контакти, історія і працівники беруться з CMS. Стартові WebP автоматично додаються в порожні медіаполя під час запуску Strapi. Модель галереї є в CMS, але публічної сторінки галереї немає.

## CMS

Схеми лежать у `cms/src/api/*/content-types/*/schema.json`. `cms/src/index.ts` під час запуску додає демонстраційні записи до деяких порожніх колекцій, але події більше не створює; також надає ролі `Public` права `find`/`findOne` для читання вмісту. Дані зберігаються в локальній SQLite-базі `cms/.tmp/data.db`.

Усі нинішні моделі мають `draftAndPublish` та Strapi i18n з українською основною й англійською додатковою локалями. [Інтерфейс адмінки підтримує українську](admin-ukrainian.md), а [контент перекладається окремо](multilingual.md). `frontend/src/lib/locale.jsx` зберігає вибір мови, `api.js` поєднує переклади з українськими записами без перекладу, а перемикач UA/EN працює в `AppLayout.jsx`.

## Межі Git

Код, схеми, документація, стартові записи та [очищений знімок локальної бази](database-backup.md) з фото зберігаються в репозиторії. `cms/.env` і робоча `cms/.tmp/data.db` ігноруються Git. Новий контент у CMS не потрапляє автоматично до Git: знімок потрібно оновити окремо. Перед перенесенням чи зміною схеми потрібні резервне копіювання та план міграції контенту.
