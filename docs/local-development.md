# Локальна розробка

## Передумови

- Node.js 22 (у поточному Windows-середовищі встановлено `22.23.3` через nvm).
- npm, який постачається з Node.js.
- Два вікна PowerShell: одне для CMS, друге для сайту.

Перевірте версію командою `node -v`. Якщо nvm показує іншу активну версію, виконайте `nvm use 22.23.3`. У PowerShell запускайте `npm.cmd`, оскільки `npm.ps1` може блокуватися політикою виконання скриптів.

## Налаштування CMS

У `cms/.env.example` наведено перелік потрібних змінних. Для нового робочого місця створіть `cms/.env` за цим зразком і **замініть усі значення `change-me` на власні випадкові секрети**. `APP_KEYS` має містити щонайменше два ключі через кому. Якщо `cms/.env` уже є, не перезаписуйте його.

`cms/.env` і `cms/.tmp/data.db` ігноруються Git. Не додавайте секрети й базу даних до комітів.

## Запуск

У першому вікні PowerShell, починаючи з кореня клону:

```powershell
nvm use 22.23.3
node -v
cd cms
npm.cmd install
npm.cmd run build
npm.cmd run develop
```

`build` потрібен для збирання адмінки; під час подальшої роботи `develop` підтримує локальний режим розробки. При першому відкритті <http://localhost:1337/admin> створіть адміністратора. API доступне за <http://localhost:1337/api>.

У другому вікні, також починаючи з кореня клону:

```powershell
node -v
cd frontend
npm.cmd install
npm.cmd run dev
```

Відкрийте <http://localhost:5174/>. Для зупинки кожного сервера натисніть `Ctrl+C` у відповідному вікні. Порти 1337 і 5174 мають бути вільними перед запуском.

## Перевірка зв'язку

1. Відкрийте <http://localhost:1337/api/events>: очікується JSON-відповідь.
2. Відкрийте <http://localhost:5174/events>: сторінка має показати події.
3. В адмінці змініть і опублікуйте тестову подію, потім перезавантажте сторінку подій.

Публічний сайт читає лише опублікований контент. Якщо API недоступне **або повертає порожню колекцію**, React зараз залишає демонстраційні записи з `frontend/src/lib/fallbackData.js`. Тому сама наявність карток на сторінці не доводить, що CMS підключена.

## Адреса API

Типова адреса задана у `frontend/src/lib/api.js`: `http://localhost:1337/api`. Для іншого сервера перед `npm.cmd run dev` задайте `$env:VITE_STRAPI_API_URL = 'http://інший-хост:1337/api'`. Джерело запиту має бути дозволене в `cms/config/middlewares.ts` (CORS).

## Якщо запуск не вдається

- `npm.ps1 cannot be loaded`: використовуйте `npm.cmd`.
- `node -v` показує 21: активуйте Node 22 через nvm перед запуском.
- Порт зайнятий: зупиніть попередній процес, що використовує 1337 або 5174.
- Адмінка не відкривається, хоча API працює: виконайте `npm.cmd run build` і повторно запустіть `npm.cmd run develop`.
- `spawn EPERM` у терміналі Codex: запускайте команди у звичайному PowerShell Windows; збирачі створюють дочірні процеси.
