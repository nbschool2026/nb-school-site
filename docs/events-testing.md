# Як перевірити події через CMS

## Запуск після зміни моделі

Зупиніть CMS і frontend у двох вікнах PowerShell (`Ctrl+C`). Зробіть копію `cms/.tmp/data.db` та `cms/public/uploads/`, якщо вони існують і містять потрібні дані. Після цього у корені проєкту запустіть:

```powershell
cd C:\Users\kvlad\Documents\Codex\nb-school-site\cms
npm.cmd run develop
```

У другому вікні:

```powershell
cd C:\Users\kvlad\Documents\Codex\nb-school-site\frontend
npm.cmd run dev
```

Якщо збірка CMS вимагає оновлення адмінки, зупиніть її, виконайте `npm.cmd run build` у `cms/` і повторіть `npm.cmd run develop`.

## Перевірка редактором

1. Відкрийте <http://localhost:1337/admin> → **Content Manager** → **Event** → **Create new entry**.
2. Укажіть унікальну назву й `slug`, дату (наприклад, 15 вересня 2026 року), категорію `sport`, короткий опис і повний текст.
3. У полі `cover` додайте обкладинку. У `photos` додайте щонайменше два фото. У `youtubeUrl` вставте звичайне посилання на YouTube-відео (`https://www.youtube.com/watch?v=...` або `https://youtu.be/...`).
4. Збережіть і натисніть **Publish**. Чернетки публічне API не показує.
5. Відкрийте <http://localhost:5174/events>. Подія має бути у списку за датою; її картка має показати обкладинку. Натисніть **Читати далі**: має відкритися окрема сторінка з повним текстом, перемиканням фото та вбудованим відео.
6. Поверніться до `/events`. Стрілками календаря перейдіть до вересня 2026 року, натисніть **Показати цей місяць**, потім категорію **Спорт**. Має залишитися створена спортивна подія вересня. Виберіть **Академічні**: якщо таких подій у вересні немає, має з'явитися «Подій не знайдено».
7. Натисніть **Скинути місяць** — категорія має залишитися вибраною. Натисніть **Усі події** — мають повернутися події всіх категорій.

Щоб перевірити сортування, створіть і опублікуйте другу подію з іншою датою. Подія з пізнішою датою має стояти вище. Якщо подію не видно, перевірте її статус **Published**, дату, доступність <http://localhost:1337/api/events> і консоль браузера. Якщо CMS недоступна, сайт показує повідомлення про помилку замість демонстраційних подій.

Календар: сьогоднішній день має велике помаранчеве коло; дні подій — менші кольорові кола за категоріями. У двох демонстраційних подій 21 травня 2026 року категорії різні; колір дня має відповідати першій з них у списку. Демонстраційні записи в локальній CMS позначені «ДЕМО» та не є реальними анонсами.
