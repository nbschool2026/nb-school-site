# Українська мова адмінки Strapi

У `cms/src/admin/app.ts` для панелі керування ввімкнено українську (`uk`) та англійську (`en`). Для нового браузера українська вибирається під час першого відкриття; уже збережений вибір мови користувача не перезаписується. Назви восьми моделей цього сайту в Content Manager задані українською. Підписи їхніх полів у списках і формах встановлює `cms/src/content-manager-labels.ts` під час запуску Strapi. Підписи, які редактор уже змінив вручну, код не перезаписує. Основний переклад інтерфейсу постачається зі Strapi 5.56; окремий пакет не потрібен.

## Як застосувати зміни

Після `git pull` зупиніть Strapi (`Ctrl+C`) та в корені репозиторію запустіть:

```powershell
cd cms
npm.cmd ci
npm.cmd run build
npm.cmd run develop
```

Оновіть <http://localhost:1337/admin>. Якщо ваш профіль раніше мав англійську мову, відкрийте меню свого профілю → **Profile** → **Interface language** → **Українська** → **Save**. На сторінці входу мову можна вибрати окремим перемикачем. Зміна мови інтерфейсу зберігається для кожного адміністратора окремо.

Для поточного локального адміністратора мову вже встановлено на `uk` у робочій SQLite-базі. У Git-знімку адміністраторів немає, тому після відновлення бази або створення нового облікового запису мову можна вибрати знову в профілі.

## Що перевірити

1. Панель входу та меню адміністратора показують українські назви.
2. Content Manager відображає «Подія», «Працівник», «Профіль ліцею» та інші українські назви моделей. У формі події поля мають назви «Назва», «Дата події», «Фотографії» тощо.
3. Створення й редагування події працює як раніше; API-шляхи та назви полів у коді не змінювалися.

Деякі написи сторонніх і нових розділів Strapi можуть залишатися англійськими: вбудований переклад не охоплює всі ключі. Мова інтерфейсу адмінки та локаль контенту — окремі налаштування. Для української/англійської версій записів див. [інструкцію з перекладів](multilingual.md).
