# Перевірка накладок і Excel-розклад

Скрипт читає опублікований розклад через локальний Strapi API, перевіряє накладки за фактичним часом уроків і створює Excel-книгу.

## Встановлення на сервері

```bash
cd /opt/nb-school-site/cms
npm install
```

Якщо залежність ще не була встановлена:

```bash
npm install exceljs --save
```

## Запуск

```bash
cd /opt/nb-school-site/cms
npm run schedule:review -- schedule-review.xlsx
```

Результат:

- `schedule-review.xlsx` — аркуш `Дані`, аркуш `Накладки`, окремі аркуші класів і вчителів;
- `schedule-review-overlaps.csv` — список знайдених накладок.

Для іншої адреси API:

```bash
SCHEDULE_API_URL=http://127.0.0.1:1337/api/schedule-lessons npm run schedule:review -- schedule-review.xlsx
```

## Як працює Excel

Аркуш `Дані` є єдиним місцем редагування. Аркуші класів і вчителів містять звичайні формули-посилання на рядки аркуша `Дані` і автоматично показують зміни з нього. Після додавання нових рядків або зміни групування потрібно повторно запустити скрипт, щоб перебудувати набір аркушів. Аркуш `Накладки` є звітом на момент запуску, тому після редагування даних його також треба оновити повторним запуском.

Скрипт шукає накладки окремо для класів, учителів і кабінетів. Накладка означає, що два часові інтервали перетинаються, навіть якщо номери уроків різні.
